## **Задача 1: Определите имена и телефоны клиентов, которые в одном заказе указали не менее двух игр с разными названиями.**

Отношения: ПЗ (ПОЗИЦИЯ ЗАКАЗА), З (ЗАКАЗ), К (КЛИЕНТ).

1. Берем проекцию номеров заказов и названий игр из таблицы позиций заказа, чтобы оставить только нужные для сравнения данные.
    $R_1 = \pi_{\text{Номер}, \text{Название}} (\text{ПЗ})$
2. Создаем копию этого отношения для последующего сравнения.
    $R_1' = R_1$
3. Соединяем отношение с самим собой по условию: номер заказа совпадает, а названия игр отличаются. Так мы находим заказы, где есть хотя бы две разные игры.
    $R_2 = R_1 \bowtie_{R_1.\text{Номер} = R_1'.\text{Номер} \land R_1.\text{Название} \neq R_1'.\text{Название}} R_1'$
4. Оставляем только номера таких заказов, отсекая лишние столбцы.
    $R_3 = \pi_{R_1.\text{Номер}} (R_2)$
5. Берем проекцию номеров заказов и идентификаторов клиентов из таблицы заказов.
    $R_4 = \pi_{\text{Номер}, \text{Ид клиента}} (\text{З})$
6. Соединяем отфильтрованные номера заказов с данными о заказах, чтобы узнать, кто их сделал.
    $R_5 = R_3 \bowtie_{R_3.\text{Номер} = R_4.\text{Номер}} R_4$
7. Выделяем только идентификаторы клиентов.
    $R_6 = \pi_{R_4.\text{Ид клиента}} (R_5)$
8. Соединяем полученные идентификаторы с таблицей клиентов, чтобы получить контактные данные.
    $R_7 = R_6 \bowtie_{R_6.\text{Ид клиента} = \text{К}.\text{Ид клиента}} \text{К}$
9. Берем финальную проекцию нужных атрибутов - имя и телефон.
    $R_8 = \pi_{\text{Имя}, \text{Телефон}} (R_7)$
    

## **Задача 2: Найдите таб. номер сотрудника, оформившего заказ, который включает игру с минимальным возрастом игроков 12 лет.**

Отношения: И (ИГРА), ПЗ (ПОЗИЦИЯ ЗАКАЗА), З (ЗАКАЗ).

1. Делаем выборку из таблицы игр по условию: минимальный возраст равен 12.
    $R_1 = \sigma_{\text{Мин возраст}=12} (\text{И})$
2. Оставляем только название игры и производителя, так как именно по ним идет связь с позициями заказа.
    $R_2 = \pi_{\text{Название}, \text{Производитель}} (R_1)$
3. Выделяем нужные столбцы из таблицы позиций заказа для соединения.
    $R_3 = \pi_{\text{Номер}, \text{Название}, \text{Производитель}} (\text{ПЗ})$
4. Соединяем отфильтрованные игры с позициями заказа, чтобы найти, в каких заказах они присутствуют.
    $R_4 = R_2 \bowtie_{R_2.\text{Название} = R_3.\text{Название} \land R_2.\text{Производитель} = R_3.\text{Производитель}} R_3$
5. Выделяем номера этих заказов.
    $R_5 = \pi_{R_3.\text{Номер}} (R_4)$
6. Соединяем полученные номера заказов с таблицей заказов, чтобы выйти на сотрудника.
    $R_6 = R_5 \bowtie_{R_5.\text{Номер} = \text{З}.\text{Номер}} \text{З}$
7. Берем финальную проекцию - табельный номер сотрудника.
    $R_7 = \pi_{\text{Таб номер}} (R_6)$

## **Задача 3: Найдите фамилии, имена клиентов, купивших игры, с минимальным количеством игроков 2, а максимальном - 6.**

Отношения: И (ИГРА), ПЗ (ПОЗИЦИЯ ЗАКАЗА), З (ЗАКАЗ), К (КЛИЕНТ).

1. Делаем выборку из таблицы игр по двум условиям сразу: минимальное количество игроков равно 2, а максимальное равно 6.
    $R_1 = \sigma_{\text{Мин игроков}=2 \land \text{Макс игроков}=6} (\text{И})$
2. Оставляем название и производителя этих подходящих игр.
    $R_2 = \pi_{\text{Название}, \text{Производитель}} (R_1)$
3. Оставляем необходимые столбцы из таблицы позиций заказа.
    $R_3 = \pi_{\text{Номер}, \text{Название}, \text{Производитель}} (\text{ПЗ})$
4. Находим заказы, содержащие эти игры, выполнив соединение по названию и производителю.
    $R_4 = R_2 \bowtie_{R_2.\text{Название} = R_3.\text{Название} \land R_2.\text{Производитель} = R_3.\text{Производитель}} R_3$
5. Оставляем только номера найденных заказов.
    $R_5 = \pi_{R_3.\text{Номер}} (R_4)$
6. Соединяем номера заказов с таблицей заказов, чтобы узнать идентификаторы клиентов.
    $R_6 = R_5 \bowtie_{R_5.\text{Номер} = \text{З}.\text{Номер}} \text{З}$
7. Выделяем идентификаторы клиентов из полученного результата.
    $R_7 = \pi_{\text{З}.\text{Ид клиента}} (R_6)$
8. Соединяем идентификаторы с таблицей клиентов для получения их личных данных.
    $R_8 = R_7 \bowtie_{R_7.\text{Ид клиента} = \text{К}.\text{Ид клиента}} \text{К}$
9. Берем финальную проекцию нужных атрибутов - фамилия и имя.
    $R_9 = \pi_{\text{Фамилия}, \text{Имя}} (R_8)$
