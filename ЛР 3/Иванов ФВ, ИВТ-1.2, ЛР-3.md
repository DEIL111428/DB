## **Задача 1: Определите адреса клиентов, заказывавших игры с доставкой.**

Здесь нам понадобятся отношения `З (ЗАКАЗ)` и `К (КЛИЕНТ)`.

1. Сначала делаем выборку (селект) из таблицы заказов по условию получения "Доставка". $R_1 = \sigma_{Получение='Доставка'} (З)$
2. Затем соединяем полученный результат с таблицей клиентов по атрибуту `Ид клиента`. Естественное соединение или соединение по условию подойдет. $R_2 = R_1 \bowtie К$
3. Оставляем только нужный нам столбец - берем проекцию по атрибуту `Адрес`. 
	$R_3 = \pi_{Адрес} (R_2)$
## **Задача 2: Определите название и производителя игры (игр), в которую можно играть самой большой компанией.**

Здесь применяется прием поиска экстремума (максимального значения). Суть в том, чтобы сравнить отношение `И (ИГРА)` с его же копией.

1. Оставим только необходимые атрибуты из таблицы игр. $R_1 = \pi_{Название, Производитель, Макс\ игроков} (И)$
2. Создадим копию этого отношения для сравнения. - $R_1' = R_1$
3. Соединим их по условию, при котором максимальное количество игроков в первом отношении строго меньше, чем во втором. $R_2 = R_1 \bowtie_{R_1.Макс\ игроков < R_1'.Макс\ игроков} R_1'$
4. Возьмем проекцию левой части - это будут все игры, которые точно не являются играми для самой большой компании (потому что нашлась игра с бОльшим значением). $R_3 = \pi_{R_1.Название, R_1.Производитель, R_1.Макс\ игроков} (R_2)$
5. Теперь вычтем из исходного списка игр те, которые мы отсеяли на предыдущем шаге. $R_4 = R_1 \setminus R_3$
6. В результате R4​ останутся только игры с максимальным количеством игроков. Берем проекцию нужных полей. $R_5 = \pi_{Название, Производитель} (R_4)$
    
## **Задача 3: Определить табельный номер сотрудника, назначенного ответственным только за один заказ (на момент выполнения запроса).**

Нам нужно найти тех, у кого больше одного заказа, и исключить их из общего списка сотрудников с заказами. Используем отношение `З (ЗАКАЗ)`.

1. Возьмем проекцию номеров заказов и табельных номеров сотрудников. $R_1 = \pi_{Номер, Таб\ номер} (З)$
2. Создадим копию. $R_1' = R_1$
3. Соединим отношение с самим собой по условию: табельный номер совпадает, а номер заказа отличается. Это даст нам пары заказов, обрабатываемых одним и тем же сотрудником. $R_2 = R_1 \bowtie_{R_1.Таб\ номер = R_1'.Таб\ номер \land R_1.Номер \neq R_1'.Номер} R_1'$
4. Выделим табельные номера тех сотрудников, которые попали в R2​. Это сотрудники, у которых 2 и более заказа. $R_3 = \pi_{R_1.Таб\ номер} (R_2)$
5. Получим список всех сотрудников, у которых есть хотя бы один заказ.$R_4 = \pi_{Таб\ номер} (З)$
6. Вычтем из всех активных сотрудников тех, у кого больше одного заказа. Оставшиеся - это те, кто ведет ровно один заказ. $R_5 = R_4 \setminus R_3$
