```SQL
-- -----------------------------------------------------
-- Table `mydb`.`Orders`
-- -----------------------------------------------------
CREATE TABLE IF NOT EXISTS `mydb`.`Orders` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `shop_id` INT NOT NULL,
  `product_id` INT NOT NULL,
  `fio` INT NOT NULL,
  `date` DATE NULL,
  `quantity` TINYINT NULL,
  `tel` VARCHAR(100) NULL,
  `confirm` TINYINT NULL,
  PRIMARY KEY (`id`, `shop_id`, `product_id`, `fio`),
  INDEX `shops_to_orders_idx` (`shop_id` ASC) VISIBLE,
  INDEX `products_to_orders_idx` (`shop_id` ASC, `product_id` ASC) VISIBLE,
  CONSTRAINT `shops_to_orders`
    FOREIGN KEY (`shop_id`)
    REFERENCES `mydb`.`Shops` (`id`)
    ON DELETE CASCADE
    ON UPDATE CASCADE,
  CONSTRAINT `products_to_orders`
    FOREIGN KEY (`shop_id` , `product_id`)
    REFERENCES `mydb`.`Products` (`shop_id` , `id`)
    ON DELETE CASCADE
    ON UPDATE CASCADE)
ENGINE = InnoDB;
```
### Ошибки в тексте
- **Таблица `products`**:
    - В тексте упоминается поле `name` для названия товара, но на скриншоте его нет, так как это сочли нерациональным.
    - Параметр `name` (название магазина) в этой таблице также является лишним, так как магазин уже привязан через `shop_id`.
- **Таблица `orders`**:
    - В тексте указано, что поле `tel` должно иметь длину 255 символов.
    - На изображении же четко указано `tel VARCHAR(100)`.
- **Таблица `deliveries`**:
    - В тексте для поля `time` (желаемое время доставки) предлагается длина 255 символов.
    - На скриншоте задано `time VARCHAR(45)`.
- **Типы данных (логические поля)**:
    - В тексте для полей `confirm` в таблицах `orders` и `deliveries` предлагается логический тип.
    - На изображении используется тип `BOOL`, однако в MySQL Workbench при выборе `BOOLEAN` тип данных автоматически заменяется на `TINYINT`.

## Задание 4
- **Целостность БД**: СУБД автоматически отследит связи.   
- **Цепная реакция**: Поскольку для всех связей был установлен параметр `ON DELETE CASCADE`, вместе с магазином исчезнут:
    1. Все товары, привязанные к этому магазину в таблице `Products`.
    2. Все заказы на эти товары в таблице `Orders`.
    3. Все записи о доставках этих заказов в таблице `Deliveries`.
